# Legal Income Helper App

Une application web simple pour aider les débutants au Sénégal à choisir un modèle de revenu légal basé sur les infoproduits et des compétences simples.

## Objectif

Créer un plan réaliste pour atteindre 1000 $/mois avec un projet légal, simple à lancer et facile à tester.

## Fonctionnalités

- questionnaire rapide sur les compétences, le temps et le budget
- recommandations d'idées d'infoproduits adaptées au niveau débutant
- plan de vente, prix et étapes de mise en route
- checklist des bonnes pratiques légales au Sénégal
- plan d'action sur 30 jours

## Lancer l'application

Depuis le dossier du projet :

```bash
python3 -m http.server 8000
```

Puis ouvrir :

```text
http://localhost:8000
```

## Technologie

- HTML
- CSS
- JavaScript

## Avertissement

Cette app aide à la planification et à la conformité de base. Pour les questions de droit fiscal ou d'enregistrement, vérifiez avec les autorités compétentes au Sénégal.
